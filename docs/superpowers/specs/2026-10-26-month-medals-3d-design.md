# 年度铸币套装：3D 月章与弹出查看

日期：2026-10-26　分支：`feat/month-medals`（从 main `043b5e6` 开，已含单枚查看静止停画）

## 目标

热力图下面的年度铸币套装里，12 枚月章现在是 SVG（`proof-set.js` 的 `medalSvg`）。改成：

1. 托盘里显示 3D 渲染的月章（预先画成图片）。
2. 点一枚月章，它从托盘里的原位置飞出来，进入单枚查看，可以拖动旋转、翻面；关上时飞回原位。

只做月章的弹出，陈列墙的徽章不改。

## 已定的外观（实验页 `medal-lab.html` 里用户选定的组合）

- **正面 C**：一圈抛光金属环（和外圈同一种阶段金属），每天一个孔。
  - 有活动的日子镶一颗珠子，顶面和金属齐平。
  - 两个工具都用的日子，珠子左右各半，左边是第一个工具，和热力图一致。
  - 没有活动的日子：孔里是暗色珐琅（凹点色 `SUNK`）。
  - 未来的日子：一个很小的暗点。
  - 解锁了徽章的日子：孔开大一点，嵌一圈金边（`unlock` 色）。
  - 中间是月份缩写（浅香槟色珐琅）和当月 Token（象牙白珐琅），外面一圈金属细线。
  - 尺寸常量照抄 `lab-assets/medal-config.js`：`RB`、`BEAD`、`RING`、`FUT`、`INNER_R`、`TRACK_H`、孔径 0.057 / 0.079、珠子半径 0.0555 / 0.052。
- **珠子材质「火珐琅」**：注意它不是透明玻璃。调到最后，它是一颗高光泽的彩色金属珠，参数要原样照抄：
  - 引擎 `MeshPhysicalMaterial`；
  - `color` = 宝石色，`transmission: 0`，`metalness: 0.9`，`roughness: 0.03`；
  - `envMapIntensity: 2.2`，`clearcoat: 1`，`clearcoatRoughness: 0.02`；
  - `ior: 1.77`，`specularIntensity: 1`；
  - `emissive` = 宝石色，`emissiveIntensity: 0.08`；`iridescence: 0`。
- **宝石色**：品牌色的色相，饱和度 0.85，亮度按档位取 1 档 0.70、2 档 0.62、3 档 0.55、4 档 0.48（`gemHex`，照抄实验页）。
  - 它比热力图的珐琅色更鲜、更亮，这是有意的。
- **月章上其余的珐琅都是哑光的**：正面板、月份字、数字、暗色孔。参数照抄 `tameEnamel`：
  - `clearcoat 0.25`，`clearcoatRoughness 0.35`；
  - `envMapIntensity 0.12`，`specularIntensity 0.35`，`roughness 0.68`。
  - 只用于月章，引擎原来的 `enamel` 不动。
- **背面 B3**：环带（细线圈和小珠），上弧月份全名，下弧年份，左右两点；中间是月桂环抱月份数字，开口处一颗星，底部一个品牌色的结（一个工具用它的 4 档色，两个工具用 `unlock` 色）。
- **外圈金属**：沿用现在的规则（`monthTier`，锡、铜、银、金）。

### 不带进正式版的东西

- 珠子底下的银衬片：实验页的 `foil`。火珐琅不透光，衬片看不见，每枚多出约 30 个网格，删掉。
- 实验页的其他正面（A、B）、其他材质、其他背面，以及调参开关（`TAME`、`GEM`）。

## 实现方式

### 材质：引擎加两个预设

在 `src/engine/materials.js` 加两个预设，并在 `registry.js` 的 `MATERIAL_TYPES` 里登记。参数见上。

- `enamel-matte`：哑光珐琅。
- `fired-enamel`：火珐琅珠。`emissive` 用预设颜色。

不再像实验页那样组装完再改材质。原有的预设一个都不改，所以徽章导出图保持不变。

### 配置：`src/brands/shared/month-medal.js`

和 `completionist.js` 同级，继续用 `buildBadge` 和 `mountBadge`，不进徽章注册表。

- `monthMedalConfig(medal, { tier })`：返回引擎配置。正面、背面就是上面定的那一套。
- `medal` 是纯数据：`{ year, month, tokens, days: [{ date, future, parts: [{ seriesIndex, level }], unlocks }] }`。
- 环带常量（`HAIR_R`、`BEAD_R`、`TEXT_R`）、月桂、星沿用 `completionist.js`。月桂现在没有导出，改成导出后共用，不再复制一份。

### 色板：运行时从热力图的系列算出来

月章同时用两个工具的颜色，和当前选的是哪个品牌无关，所以不写死在品牌色板里。

- `medalPalette(series)`：返回 `{ 'm:<i>:<level>': gemHex(...), sunk, future, unlock, label, ivory }`，其中 `i` 是系列序号。
- 组装时传 `{ ...brand, palette: { ...brand.palette, ...medalPalette(series) } }`，和实验页一样。

### 数据：`monthMedalData(...)`

纯函数，输入是 `{ year, month, tokens, series, partsOf, markersOn, now }`，用的是热力图现有的 `partsOf` 和 `markersOn`，和 `medalSvg` 同一个来源。

- `partsOf` 返回的 `{ color, level }` 要换成系列序号，按 `color` 对上 `series[i].color`。
- 如果实现时发现 `partsOf` 能直接给出系列 id 会更干净，可以给它加一个 `id` 字段。

### 托盘图片

- **共用陈列墙缩略图的那个舞台。** 用 `createBadgeRenderer(ctx.stage)` 截图，整页仍只有一个 WebGL 上下文（全解锁铸币另有自己的）。
- **按陈列墙缩略图的节奏画。** 用 `forEachFrame` 一帧画一枚；单枚查看打开时暂停（`pause: inspect.whenClosed`）。
- **什么时候画：** 页面空闲、陈列墙缩略图画完以后，开始画当前年份和工具开关下的 12 枚。用户先拉开抽屉的话，就立刻开始画。
  - 实测预算：12 枚冷启动约 0.6–0.9 秒，作为上限参考。
- **画好之前：** 托盘照旧显示 SVG 月章。12 张图全部解码好以后，用 0.45 秒淡入一次换上（和铸币淡入同一条曲线），不会一枚一枚地跳。
  - 系统开了“减少动态效果”时直接换，不做淡入。
- **缓存：** 存在内存里，键是 `年份 | 打开的工具（排序后）`。切换年份或工具时：
  - 有缓存就直接换；
  - 没有就先保留当前的图，新的一套画好、解码好以后再淡入替换。
  - 数据在一次页面加载里不会变，所以不做持久化缓存。
- **兜底：** 截图失败（拿不到 WebGL、上下文丢了）就一直用 SVG，`medalSvg` 留着。
- **悬停：** 珠子悬停显示当天详情的功能要保留。图片上面盖一层透明的 SVG 命中区，用和 3D 同一套 `beadAt` 坐标，每颗珠子一个带 `data-date` 的透明圆，接回现在的 `pointerover`。

### 弹出：走现有的单枚查看

和全解锁铸币一样，点开月章就用一个临时的 item 走 `ctx.emit('open', item, …)`。

- 这个 item 不在 `ctx.items` 里，陈列墙、总数和海报都不算它。
- 拖动、翻面、超采样、静止停画、导出都照旧可用。

单枚查看要加的东西：

1. **从原位置飞出、飞回。** `open(item, { from })`：
   - `from` 是托盘槽位的屏幕矩形。徽章从这个位置和大小开始，补间到中央的布局位置。
   - 托盘里那一格同时变成空凹槽（槽位加 `is-out`，图片隐藏，凹槽保留）。
   - 关上时如果槽位还在屏幕里，就沿原路飞回、落进凹槽，然后去掉 `is-out`；槽位不在屏幕里就照现在的方式关。
   - 实验页的顺序和时长可以参考，但正式版以单枚查看现有的打开节奏为准，不另起一套补间。
   - 实验页里那一步“原位抬起 4px、放大 1.04 倍、0.19 秒”保留，作为托盘里的预备动作。
   - 系统开了“减少动态效果”时只做淡入淡出。
2. **月章专用的信息区**（`fillInfo` 加一个分支）：
   - 小标题：年份和外圈金属，例如“2026 · 银”；
   - 标题：月份（中文“4 月”、英文“April”），中文界面下面一行英文写“APRIL 2026”；
   - 三行数字：Token、活跃天数、解锁徽章；
   - 图例：每个工具一个色块，“同一天都用”一个左右各半的色块，“解锁徽章”一个金边圈。
   - 图例色块用宝石色，和珠子一致，不用热力图的珐琅色。
   - 隐藏等级阶梯、进度条和“重播获得动画”（`award: false`）。
   - 所有文案中英文都要有，写进 `i18n`。
3. **地址栏的 hash**：月章不写 `#id`，月章不能通过链接直接打开。

### 托盘槽位的可访问性

- 铸好的月章槽位从 `role="img"` 改成按钮，加 `tabindex="0"`，Enter 和 Space 打开。读屏名字沿用 `proof.medal`。
- 关上后焦点回到这个槽位。
- 只有用键盘打开时，焦点框才显示：用 `:focus-visible`，并把 `viaKeyboard` 一路传下去。这修掉了实验页报告里的“Esc 关上后焦点框落在月章上”。
- 空槽位（还没铸的月份）不变。

## 测试

- **单元测试：**
  - `monthMedalConfig`：
    - 珠子数等于当月天数；
    - 未来的日子、没有活动的日子、一个工具、两个工具各对应正确的件和颜色键；
    - 解锁的日子有金边；
    - 背面是 B3 的结构，结的颜色规则正确；
    - 配置能通过 `validate`。
  - `medalPalette` 和 `gemHex`：档位和亮度的对应关系，两个系列互不串色。
  - `monthMedalData`：从 `partsOf` 和 `markersOn` 正确转出数据，`now` 之后的日子标为未来。
  - 缓存键：工具顺序不同，键相同。
  - 两个新材质预设存在，参数和本文一致。
- **浏览器检查（`scripts/shoot.mjs`）：**
  - 拉开抽屉，等一会儿后铸好的月份都是 3D 图片，没铸的月份仍是空槽；
  - 换上图片时没有逐枚跳变：12 张图在同一帧出现；
  - 点一枚月章，单枚查看打开，信息区显示的是月章的数据；
  - Esc 关上，焦点回到那一格，`is-out` 已去掉；
  - 悬停一颗珠子会显示当天的提示；
  - 控制台没有报错。
  - 真实显卡和软件渲染都要过。
- **徽章导出图（`scripts/visual.mjs compare`）：** 299 张必须逐像素一致，这次不改任何徽章的外观。
- **性能（只记录，不卡）：** 记下 12 枚截图的耗时，写进最终报告。
