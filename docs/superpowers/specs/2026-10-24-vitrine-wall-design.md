# 徽章墙「陈列柜」视觉重设计 — 设计规格

- 日期：2026-10-24
- 状态：设计已确认（含 impeccable 原则复审后的三项决定），待评审规格
- 分支：`design/vitrine-wall`，从 main（`a29f4e3`，0.5.2 之后）建出
- 范围：徽章墙页面（`index.html`，本机 `npx agent-badges` 打开的页面和 GitHub Pages 上发布的个人主页是同一个页面）

## 问题

徽章是「实物」：金银铜的金属边、饱和的珐琅色块、凸起的轮廓、真实的光影，外圈是 Outfit 粗体、字距拉开的大写字母和小星号点缀。徽章周围的界面却是「通用的深色后台」：圆角矩形卡片、一像素浅色描边、平涂背景，进度环和按钮都是同一种珊瑚橙，热力图沿用 GitHub 贡献图的方格。两套视觉语言放在一起，徽章像被摆进了管理后台，而不是陈列柜。

具体表现：

- 热力图和进度环是页面上最「数字」的东西，却放在最显眼的位置。365 个高饱和的方块加上斜切双色和小白点，比徽章本身还吵。
- 背景接近纯黑（`#141413`），金属没有可以映照的环境，整页单调。
- 页眉元素小而散，没有形成整体；页面没有页脚，最后一排徽章之后直接结束。

## 方向

以「陈列柜」为主，用「画廊」的克制来把握分寸：

- **陈列柜：** 整页是一个打了灯的勋章陈列柜。界面向徽章学习，直接借用徽章自己的设计语言（外圈的字体和字距、金属双圈、小星号、等级金属色），而不是另外发明一套风格。
- **克制：** 材质只出现在三处：背景、进度区的铸币、热力图。其余地方靠留白、字体和细线组织版面。原则是「暗示材质，而不是画出材质」，避免拟物过头、显得老气。
- **避开通用套路：** 「细线分隔 + 衬线大标题 + 字距拉开的小标签 + 暖色暗底」是 AI 生成界面最常见的一种套路。本设计让界面区别于这种套路的，是只有这个产品才有的东西：真实渲染的铸币、珐琅刻点、徽章同款字体、四角星、金属滑块。实现时如果某处只剩通用的细线和小标签，就是做偏了。

## 已做的取舍

- **页面顺序保持不变：** 页眉 → 概览 → 热力图 → 徽章墙 → 页脚。电脑屏幕的第一屏看不到徽章墙，这是有意保留的：用户更看重概览和使用数据。第一屏的「展品」由概览区的 3D 铸币和「最近获得」的徽章承担。
- **字体统一到徽章的 Outfit，去掉衬线体。**
- **概览区的进度做成真正的 3D 铸币**，用画徽章的同一套引擎渲染。

## 范围

改：

- 徽章墙主视图：页眉、概览区（含 3D 铸币）、热力图、徽章分区标题、筛选控件，新增页脚。
- 弹层（单枚查看、分享海报弹窗、GitHub 主页图弹窗、导出面板、通知）：不改结构，只换成新的颜色、字体和控件变量，保持全页一致。

不改：

- 已有徽章的 3D 渲染、缩略图、刻字。
- 分享海报和 GitHub 主页图这两张生成的图片（`src/viewer/poster.js`、`src/viewer/shelf.js` 画在画布上的内容）。
- 落地页（`landing.html`、`src/site/`），以后单独做。
- 页面的数据、交互和功能：悬停详情、点击打开徽章、年份切换、工具开关、筛选、语言切换的行为都保持不变。

## 第 1 节：设计基础

全页共用的规则，定义成 `src/styles/tokens.css` 里的变量。后面各节和弹层都只从这里取值。下面给出的色值是起点，第一次截图评审时可以微调；调整只改变量，不改用法。

### 1.1 背景

- 底色从 `#141413` 换成**只微微偏暖、接近中性**的深色，不要明显的棕调，避免整页变成「单调的棕金色」。起点：`--bg: #141312`，`--bg-lift: #242220`。
- 顶光：页面顶部中央一束柔和的光，从上往下渐暗（径向渐变，中心在页面顶部中央偏上，`--bg-lift` 过渡到 `--bg`）。
- 暗角：四周边缘再微微压暗，形成纵深。
- 纹理：一张小尺寸的平铺纹理（约 128×128 的细颗粒，内联 SVG 数据 URI 或一张小 PNG），作为背景图片平铺，透明度 3%–4%。**不对页面内容施加实时的 `filter`**，避免滚动时持续重绘。近看有织物质感，远看仍是干净的深色；颗粒也能消除暗色渐变的色带。
- 背景固定，不随滚动移动（沿用现在的 `background-attachment: fixed`）。
- 色彩由徽章的珐琅色承担，界面只负责托住它们。

### 1.2 颜色

- **金色是界面唯一的强调色**，取代珊瑚橙 `--accent: #d97757`。只用于小面积元素：胶囊滑块、主按钮、热力图的解锁标记、装饰线和四角星。
- 金色基于等级金属的金 `#f2c46b`，界面用一个更沉、饱和度更低的版本，避免和金级徽章抢眼。起点：`--gold: #c9a45c`；装饰细线用它的低透明度版本 `--gold-line`（约 0.35）。
- **CSS 里的金属感**：只用在胶囊滑块和主按钮这两种小面积实心元素上，用一个很轻的线性渐变加顶边一像素高光表现（`--metal-gold`），不画假的高光反射。大面积元素一律不用。真正的金属由 3D 铸币来呈现（第 3 节）。
- **等级金属**：银、铜等颜色只在提到徽章等级的地方出现，沿用 `controls.css` 里现有的 `[data-metal]` 变量，不改。
- **品牌色只用于数据**：Claude Code 的橙和 Codex 的蓝（`brand.color`）只出现在热力图的珐琅点、工具图例、热力图悬停详情里，不再用于装饰界面。页眉左侧的标志也不再是橙色。
- 文字色：`--text`、`--muted`、`--faint` 随新底色调整。正文和次要文字对新背景的对比度都要达到 WCAG AA（至少 4.5:1）；`--faint` 只用于不承载信息的装饰。

### 1.3 字体

**界面字体统一到徽章外圈用的 Outfit，不再使用衬线体。**

- **Outfit**：项目已有开发依赖 `@fontsource/outfit`（SIL OFL 1.1），徽章外圈的字形就是从它提取的（`src/engine/fonts/ring-font.json`）。页面打包它的拉丁子集，只用两种字重：500（标签、正文中的英文和数字）和 700（大数字、标题）。字体文件随页面一起构建、本地加载，不从网络获取；`font-display: swap`。
- **中文**：继续用系统字体（苹方等，现有 `--sans` 里的中文部分），层级靠字号、字重和字距区分。
- **大数字**（解锁数、累计 Token、活跃天数、最长连续、分区计数）：Outfit 700，等宽数字（`font-variant-numeric: tabular-nums`）。
- **标题**（页面工具名、分区标题、「年度热力图」）：英文和数字用 Outfit 700，中文用系统字体的中粗字重。
- **小标签**（「最近获得」「即将解锁」、月份、日期等）：字距拉开。英文用 Outfit 500 大写，字距约 0.18em，这正是徽章外圈「CLAUDE CODE」的排法；中文同样拉开字距（约 0.12em），字号稍小。
- **正文和数据说明**：Outfit 500 加系统中文字体，保证易读。
- 现有的 `--serif` 变量从页面样式中移除；分享海报和主页图的画布绘制不在本次范围内，保持原样。

### 1.4 线条与装饰

- **去掉卡片**：概览区的三张圆角卡片和热力图的大卡片都去掉，不再有圆角矩形的底和边框。
- **细双线**取代卡片边框和分隔单线：两条一像素的 `--gold-line` 细线，中间留 2px 空隙，像徽章的金属双圈。
- **四角星**：一个小的四角星图形（内联 SVG），和徽章外圈两侧的星号同形。只用在三处：页眉标志、概览区上方双线的正中、页脚双线的正中。不在其他地方使用。

### 1.5 胶囊控件

全页所有「多选一」和「开关」控件统一成一种胶囊，定义在 `controls.css`：

- 外形：细长胶囊，`--gold-line` 细线描边，底色比背景略深，像刻在面板上的一道槽。
- 当前项：下面垫一块金属滑块（`--metal-gold`），文字为深色；其余项文字为 `--muted`。
- 切换时滑块平滑滑到新位置（约 220ms，缓出曲线）。系统开启「减少动态效果」（`prefers-reduced-motion: reduce`）时直接切换，不播动画。
- 键盘可操作，`focus-visible` 时有清楚的金色焦点环。
- 用于：语言切换、徽章筛选（全部 / 已获得 / 未解锁）、热力图年份切换。热力图的工具开关可以多选，用同一种胶囊外形，但每个工具是独立的开关，打开时垫滑块，关闭时只剩文字。

## 第 2 节：页眉

- **标志**：橙色小菱形换成金色四角星。
- **工具标签**：「Claude Code / Codex」用 Outfit 700。当前工具更亮，下面一道短金色细线；另一个变暗。
- **副标题**：「成就徽章」改成字距拉开的小字。
- **右侧**：「示例数据」改成同风格的小字标签，只在使用示例数据时出现（行为不变）。
- **语言切换**：换成胶囊，里面并排写「中」和「EN」，当前语言下面垫金属滑块。点击另一侧切换语言，切换方式沿用现在的链接（`[data-lang-switch]` 的跳转逻辑不变，只是变成两个选项）。
- 页眉固定在顶部（行为不变）。滚动后的底部渐隐改用新底色。

## 第 3 节：概览区（铭牌 + 3D 铸币）

整个概览区是一块完整的铭牌，取代三张卡片：

- 上下各一道细双线，上方双线正中放四角星。三栏之间用竖向细线（单线，`--gold-line`）隔开。

### 3.1 左栏：3D 铸币

> 已被取代：概览区的进度铸币（本节和修正轮里的「深色精制币」）换成了实时 3D 的全解锁徽章，见 `2026-10-24-completionist-badge-design.md`。`src/engine/coin.js`、`src/viewer/coin.js` 已删除。

进度不再是 SVG 圆环，而是一枚用徽章引擎渲染的真实金属铸币：

- **造型**：圆形金币，比徽章更薄、更朴素，没有珐琅，只有金属本色。边缘一圈细密的齿纹（硬币的滚边）。币面外圈有一圈小凸点，**每个凸点代表一枚徽章**（Claude Code 32 个，Codex 30 个，按当前工具的徽章总数）：已解锁的凸点抛光发亮，未解锁的是哑光的低点。币面中央是凸起的解锁数（例如「27」），下方小字「/ 32」。
- **材质与光照**：金属材质与金级徽章同源（`src/engine/materials.js`、`tiers.js`），处在同一个场景环境和光照下（`src/viewer/scene.js`），与徽章看起来是同一套实物。
- **文字**：币面数字用 Outfit 粗体的字形轮廓做浮雕，复用徽章外圈文字的字形数据（`ring-font.json`）和浮雕工具（`src/engine/text.js`、`relief.js`）。
- **渲染方式**：页面加载后，用现有的统一渲染服务（`createBadgeRenderer` 的 `render`）把铸币画成一张静态 PNG（2 倍分辨率），放在概览区左栏，以略微倾斜的角度展示，让齿纹和侧光可见。不额外创建 WebGL 上下文，不做实时动画；切换工具或语言时重新渲染一次。
- **代码位置**：铸币的几何与组装放在 `src/engine/`（新增 `coin.js`，与徽章共用形状、材质、浮雕工具），页面中的使用放在 `src/viewer/profile.js`。分层规则不变（`tests/contracts.test.js`）。
- **兜底**：渲染失败或浏览器不支持 WebGL 时，显示一个 SVG 刻度环（120 道径向刻度，已解锁比例的刻度点亮为金色），布局不变。
- **可访问性与检查**：铸币图片带替代文字（例如「已解锁 27 / 32」）；图片旁仍保留文字形式的解锁数元素 `.profile-count`（视觉上作为铸币下方的说明文字），浏览器检查依赖它。

### 3.2 左栏的其余内容

- 三个数字（累计 Token、活跃天数、最长连续）用 Outfit 700 大字，标签用字距拉开的小字。
- 两个按钮改成胶囊形：「生成分享海报」为金属实心胶囊，「GitHub 主页图」为金色细线描边的胶囊。

### 3.3 中栏「最近获得」、右栏「即将解锁」

- 结构不变。徽章名称用 Outfit 700 / 系统中文中粗，日期和进度数字用小字。
- 进度条改成一道刻进去的细槽，已完成部分填金色。

### 3.4 手机屏幕

- 三栏改为上下排列，竖向分隔线换成横向细线；铸币和三个数字保持在第一屏可见。

## 第 4 节：热力图（珐琅刻点）

- 去掉大卡片。标题「年度热力图」按第 1.3 节的标题样式，下面的统计（总 Token、活跃天数、最长连续）改成小字。
- **格子改成圆点**，像金属板上一排排刻出的凹坑。电脑屏幕上圆点直径不小于 9px：
  - 没有活动：微微凹下去的暗点（暗色填充，加一道很淡的内阴影或下缘高光，暗示凹陷）。
  - 有活动：点里填珐琅色，用该工具的品牌色，但降低饱和度；用量越大填得越亮（沿用现有的 5 级强度）。
  - 两个工具同一天都用了：左右各半的双色珐琅，取代现在的斜切。截图时要确认在实际尺寸下两半的颜色能分辨，不会混成一种颜色。
  - 那天解锁了徽章：圆点外加一圈细金边，取代现在的小白点。
  - 未来的日子和年初的占位格：比空点更淡的轮廓点，仍然占位，保证每周一列对齐。
- 月份标签和星期标签改成字距拉开的小字。
- 年份切换改成胶囊；工具开关改成第 1.5 节的多选胶囊；图例「少 … 多」用一排逐级变亮的圆点表示，解锁标记的图例也改成金边圆点。
- 交互不变：悬停显示详情，点击带金边的圆点打开对应徽章。悬停详情浮层换成新的颜色和字体。
- 保留现有的元素标记：`.heat-cell`、`data-date`、`.is-unlock`、`.heat-years`、`.heat-brand`、`data-id`、`aria-pressed`，浏览器检查依赖它们。
- 手机屏幕：热力图仍可横向滚动，看今年时滚到最右（行为不变），页面本身不能出现横向滚动。

## 第 5 节：徽章墙分区

- 「全部徽章」标题按第 1.3 节的标题样式，筛选改成胶囊（数量仍显示在每个选项里）。
- 每个分类（里程碑、连续与习惯……）下方的单线改成细双线；右侧计数「8 / 8」用 Outfit 700 等宽数字。
- 徽章下方的名称、日期、等级圆点只换字体（名称用 Outfit / 系统中文），位置和内容不变。徽章本身不变。

## 第 6 节：页脚（新增）

- 最后一排徽章之后，留出足够的空白，然后一道细双线，正中四角星。
- 下面一行居中的小字，像藏品图录的版权页：`AGENT BADGES · v<版本号> · GitHub`。
  - 版本号在构建时从 `package.json` 读入（Vite 的 `define`，例如 `__APP_VERSION__`），不硬编码。
  - 「GitHub」链接到项目仓库 `https://github.com/Aryous/agent-badges`，新标签页打开。
- 中英文各一套文案，放进现有的 i18n 字典。
- 不显示「数据更新于」：页面拿不到数据的采集日期，要显示需要改数据格式和采集流程，不在这次范围内。

## 第 7 节：弹层

单枚查看（`inspector.css`）、分享海报弹窗与 GitHub 主页图弹窗（`modal.css`）、导出面板（`export.css`）、通知（`notice.css`）：

- 把写死的颜色换成第 1 节的变量：底色、文字色、细线、强调色。
- 按钮和分段控件换成第 1.5 节的胶囊。
- 字体按第 1.3 节：标题和数字用 Outfit 700，小标签用字距拉开的小字，不再使用衬线体。
- 不改布局、不改结构、不改交互。

## 实施顺序与评审节点

审美好坏测试判断不了，所以分两段，中间停下来请用户看效果：

1. **第一段**：第 1 节设计基础（含字体打包）、第 1.5 节胶囊控件、第 2 节页眉、第 3 节概览区（含 3D 铸币）。完成后：
   - 拍电脑（1440×900）和手机（390×844）的截图，另拍一张铸币的放大图；
   - 用 impeccable 的评审命令（`critique`，设计评审与自动检测各由一个子代理独立完成）审一次实际页面；
   - 截图和评审结果一起交给用户。用户认可方向（或给出调整意见并改完）后才进入第二段。
2. **第二段**：第 4 节热力图、第 5 节分区、第 6 节页脚、第 7 节弹层。完成后再拍一组截图、再做一次 impeccable 评审，交给用户。

合并到 main 和发布新版本，都等用户看过最终效果后再决定。

## 验收标准

- **徽章渲染零变化**：用 `scripts/visual.mjs` 在改动前后各拍一次（同一天拍），299 张徽章图逐像素一致。这证明铸币和界面改动没有碰到徽章。
- **功能不坏**：`npm run check:browser` 全部通过，包括手机端陈列墙（含热力图）无横向溢出。必要时只调整检查里依赖旧外观的部分（例如颜色），不得放宽功能判断。新增一项检查：概览区的铸币图片已渲染（不是兜底的刻度环），且替代文字里的解锁数与陈列墙一致。
- **兜底可用**：在禁用 WebGL 的条件下打开页面，概览区显示刻度环，布局不乱。
- **单元测试**：`npm test` 全部通过，包括分层规则；新增铸币的单元测试：凸点数量等于当前工具的徽章总数，已解锁凸点数量等于解锁数。`npm run check:pack` 通过（字体打包和版本号注入不能破坏打包）。
- **对比度**：正文和次要文字对新背景达到 WCAG AA（4.5:1）。
- **减少动态效果**：开启 `prefers-reduced-motion` 时，胶囊滑块不播动画。
- **依赖**：不新增运行时依赖；字体来自已有的开发依赖 `@fontsource/outfit`，随页面构建本地加载，不引入网络字体和外部图片。
- **性能**：铸币渲染不新建 WebGL 上下文，复用统一渲染服务；页面加载到概览区可交互的时间，与改动前相比不得明显变慢（在本机用示例数据各测一次，记录在交付说明里）。
- **截图**：每个评审节点提供一组电脑和手机截图，放在 scratchpad，并在汇报里给出完整路径。

## 修正：第一段评审后（2026-10-24）

用户在浏览器里看过第一段后指出：金属渐变的按钮和滑块像 iOS 6 的拟物设计，已经过时；整页金色太多，显得俗气、不高级。以下修正取代第 1.2、1.5、3.1 节中相应的规定，其余不变。

### 配色体系（取代第 1.2 节的强调色用法）

大致按 60 : 30 : 10 的比例，加极少量点睛色。金色不再同时承担主题色和强调色。

| 角色 | 占比 | 颜色 | 用途 |
|---|---|---|---|
| 底色（丝绒衬底） | 约 60% | 暖中性深炭 `--bg #141312`（不变） | 页面背景 |
| 中性结构色（锡、铂） | 约 30% | 偏暖锡灰金属线 `--pewter`；象牙白文字 | 控件外框、细双线、正文、次按钮 |
| 主题色（珐琅） | 约 10% | 深午夜蓝珐琅 `--enamel`，取自产品标志徽章的深蓝 | 胶囊滑块、主按钮的珐琅面 |
| 强调色（金） | 不到 2% | 低饱和香槟金 `--gold` | 四角星、当前工具下的短线、滑块和主按钮的细金边、铸币浮雕、焦点环 |
| 数据色 | 只在数据里 | `brand.ui.accent` | 热力图、工具图例 |

- 细双线（`.rule`、分区标题下方）改用锡灰 `--pewter-line`，不再用金色。
- 所有控件不使用渐变、镜面高光和厚重投影。

### 控件：把徽章的构造搬到胶囊上（取代第 1.5 节的外观）

徽章是三层：金属外圈、低一层的正面板、立在上面的珐琅与浮雕。控件复用这三层：

- **外框**：一像素锡灰金属细线，相当于徽章外圈。
- **槽**：外框里面一圈比底色更深、向内凹的轨道（一道很淡的内阴影），相当于低于外圈的正面板。
- **滑块**：一枚胶囊形的小徽章：平涂哑光的午夜蓝珐琅面，外加一圈细香槟金边，微微凸起。凸起只靠三个线索：顶边一像素很淡的亮线、底边一像素很淡的暗线、一个很小很软的投影。文字为象牙白。
- 一个零件三种用法：胶囊的当前项是滑块；**主按钮**是一枚单独的胶囊小徽章（珐琅面 + 金边 + 凸起，外面同样有锡灰外框）；**次按钮**只有锡灰外框和凹槽，没有珐琅。
- 滑动动画、减少动态效果、键盘焦点的要求不变。

### 铸币：深色精制币（取代第 3.1 节的材质）

- 币面是近乎黑色的镜面金属（与「黑瓷金」顶级徽章同一种黑），外圈滚花为金。
- 凸起的部分（已解锁凸点、中央数字、总数、珠圈细线）为磨砂金：一暗一亮的反差，金色只占少量面积。
- 未解锁凸点为低矮的暗色金属点，在黑色币面上要隐约可见、但明显弱于金色凸点。
- 铸币放大到约 184px（手机约 140px）。

### 概览区的两处修正（第一段评审 P1）

- 「已解锁徽章」从三个统计数字上方移到铸币下方，作为铸币的说明。铸币画好后，下方不再重复显示「27 / 32」数字（数字仍保留在页面中供检查使用，对读屏软件只读一次）。兜底刻度环状态下，数字照旧叠在环中显示。
- 英文版在 1024–1440px 宽度下不折行：三个统计数字固定三列；英文标签缩短（例如 Streak）；两个按钮保持一行（英文次按钮缩短为「GitHub image」）。

## 修正：第二段开工前（2026-10-24）

全解锁徽章（`2026-10-24-completionist-badge-design.md`）做完以后，用户看了三个热力图方向的原型，选了 **B · 午夜蓝珐琅板**。C（十二枚月章）存放在草稿分支 `draft/heatmap-month-medals` 的 `docs/drafts/` 里，留作以后用。参考实现：`.superpowers/sdd/heatmap-lab-reference.html` 里的方案 B（`.plate`、`.b-*`、`calendar()`、`fill()`、`legend()`）。

### 热力图：午夜蓝珐琅板

**思路：** 热力图不自己画一套材质，而是用全解锁徽章环带的那套材料：午夜蓝珐琅底、锡色双线边框、沙金色的字。品牌色在深蓝底上像徽章里的珐琅。这样热力图和上方的全解锁徽章是同一家族。

**珐琅板**（整张热力图，包括标题、点阵、图例，都放在板上）：
- 底：`#141F4D`，和徽章的 `midnight` 同色。加一层很淡的同心细纹，像徽章环带的 `rings` 底纹：`repeating-radial-gradient(circle at 50% -40%, rgba(255,255,255,.018) 0 1px, transparent 1px 4px)`。
- 圆角 18px。内边距桌面约 26px / 30px，手机酌减。
- 边框是锡色双线，像徽章的金属外圈加细线圈。写法：`inset 0 0 0 1px rgba(160,152,138,.42)`，`inset 0 0 0 5px #141F4D`，`inset 0 0 0 6px rgba(160,152,138,.22)`。外加一道柔和的投影 `0 18px 40px rgba(0,0,0,.35)`。
- 点阵和图例之间，一道锡色细双线。

**板上的字：**
- 标题「年度热力图」：`#f3ead6`。
- 统计行：字距拉开的小字 `#9aa3c4`，其中的数字 `#f3ead6`。
- 月份：沙金色 `#b8a982`。
- 星期：`#8d96b8`。
- 图例文字：`#8d96b8`，工具名 `#e6dcc4`。

**点阵**（一周一列，和现在一样）：
- 圆点。电脑上直径不小于 9px，点阵尽量撑满板的宽度。
- 没有活动：凹下去的深色点 `#0d1538`，`inset 0 1px 1.5px rgba(0,0,0,.55)`，下缘加一道很淡的高光 `0 1px 0 rgba(255,255,255,.05)`。
- 有活动：品牌色珐琅。按 5 级强度，在品牌色和 `#0d1538` 之间混色，比例依次是 0、0.38、0.58、0.8、1（等级越高越接近品牌色）。点上加一道顶部高光和底部暗边，像凸起的珐琅。
- 两个工具同一天都用了：左右各半（90°），不再斜切。
- 那天解锁了徽章：圆点外加一圈 1.2px 的金边 `#d9bf86`，离圆点 2px。
- 未来的日子和年初的占位格：淡轮廓 `rgba(184,169,130,.16)`。
- 品牌色用工具的 `brand.ui.accent`，和现在一样。

**控件放在板上：**
- 年份胶囊和工具开关仍然是第一段修正里的「徽章构造」胶囊，但要在午夜蓝底上看得清：
  - 凹槽用 `#0d1538`；
  - 滑块用比板稍亮的珐琅色，比如 `#24306a`，加金边 `--gold-rim`；
  - 外框用锡色线。
- 工具开关：打开时有滑块、品牌色圆点和工具名，关闭时只剩文字和空心圆点。具体数值由实现时看着定，原则是在板上清楚、不抢点阵。

**图例：** 颜色必须和点阵一一对应。每个工具显示它自己的四级色阶，和点阵用同一个取色函数生成；另外放一颗左右各半的点，说明「同一天都用」，再加一句「颜色越亮，当天用量越多」和金边的解锁标记。不能再用中性的米白色阶。用户在原型里指出过这一处对不上。

**悬停详情：** 深色浮层，和单枚查看的弹层同一套颜色（`--bg-lift` 底，锡色线）。

**评审里提出的两点，一起做：**
- 统计行写明范围：两个工具都开着时写「两个工具合计」，只开一个时写那个工具的名字。中英文都要。
- 星期标签的对比度要够：现在 `--faint` 是 2.9:1，改用 `#8d96b8`。

### 年度铸币套装（2026-10-24，用户在原型里选定）

参考实现，都不提交：
- `.superpowers/sdd/proof-set-lab-reference.html` 的 (c)：抽屉式滑盖，礼盒用 `case2` 版式；
- `.superpowers/sdd/pull-lab-reference.html` 的 5：皮质拉环；
- `.superpowers/sdd/heatmap-lab-reference.html` 的 C：月章，以及视觉居中的写法 `centerStack`。

**是什么：** 每一年一只铸币礼盒，藏在热力图板子的下面。每个月一枚「月章」：
- 外圈的每颗珠子是当月的一天，用得越多越亮，颜色和热力图一致，两个工具都用就左右各半，解锁徽章的日子加金圈；
- 中间写月份和当月 Token，按视觉居中，不是按坐标居中。

**发放规则：**
- 有活动的月份，从那个月开始就有一枚月章；当月的那枚跟着天数实时更新。
- 还没到的月份、整月没有活动的月份，是一个空的圆形凹槽，上面淡淡地写着月份。
- 每枚外圈的金属按当月用量分级：以这一年用量最多的那个月为准，达到它的 1/4、1/2、3/4 分别是铜、银、金，更少是锡。颜色和全解锁徽章的阶段金属同一套，不另加图例。
- 礼盒左边一块竖的黄铜铭牌：
  - 年份（大字）；
  - `PROOF SET`；
  - 一条细线下面写状态：今年是 `MINTING · n / 12`，n 是已经有月章的月份数；过去的年份是 `SEALED · 12.31`。
- 跟着热力图当前选中的年份和开着的工具走：只开一个工具时，月章只算那个工具。

**版式：**
- 礼盒和热力图板一样大，不靠拉伸凑尺寸：先量出板子的自然高度，再按它排铸币。
- 左边是铭牌栏（约 190px），右边是丝绒托盘，6 列 × 2 行。
- 铸币直径 =（高度 − 礼盒内边距 − 托盘上下内边距 − 行距）÷ 2。电脑上约 120px，不能小到看不清珠子和数字。
- 四周要留足呼吸：铸币不贴托盘边，托盘不贴礼盒边。
- 手机上托盘改成 3 列 × 4 行，礼盒比板子高：打开时盒子的高度跟着过渡到礼盒的高度，关上时再回到板子的高度。

**交互：抽屉式滑盖。** 怎么打开，就怎么原路收回：
- 板子下沿正中是一个皮质拉环：深蓝皮革、金色明线、一颗铜铆钉。悬停时轻轻翘起。
- 打开：往上拖拉环超过约 24px，或者点一下、按 Enter / Space。
  1. 板子先「抬起」：略放大到 1.012，上移 3px，阴影加深，约 0.22 秒；
  2. 再往上滑进礼盒上沿，约 0.75 秒，慢—快—慢。只裁上沿，左右和下方的阴影保留。最后只露出一道边和拉环。
  3. 铸币一枚枚落定：每枚从上方 14px、略小、透明，回弹到位，依次错开 45ms。
- 关上：往下拖拉环，或者再点、再按，倒过来走：先滑回来，再「放下」。
- 拉环是一个按钮，带 `aria-expanded` 和 `aria-controls`，有清楚的焦点样式。礼盒是 `role="region"`，名字是「2026 年度铸币套装」。
- 每枚月章有文字说明，例如「1 月：1.6B Token，23 个活跃日，金」。悬停珠子时和热力图一样显示当天详情。
- 减少动态效果：不抬起、不滑动、不落定，直接切换。
- 礼盒打开时，热力图板子上的年份和工具开关被盖住，要换年份就先关上，这是有意的。

**这一版不做：**
- 年终封存仪式：最后一枚落下、铭牌扫光；
- 把礼盒放进分享海报。

这两项以后再做。
