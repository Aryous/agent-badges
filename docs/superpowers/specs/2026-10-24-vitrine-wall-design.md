# 徽章墙「陈列柜」视觉重设计 — 设计规格

- 日期：2026-10-24
- 状态：设计已确认，待评审规格
- 分支：`design/vitrine-wall`，从 main（`a29f4e3`，0.5.2 之后）建出
- 范围：徽章墙页面（`index.html`，本机 `npx agent-badges` 打开的页面和 GitHub Pages 上发布的个人主页是同一个页面）

## 问题

徽章是「实物」：金银铜的金属边、饱和的珐琅色块、凸起的轮廓、真实的光影，外圈是字距拉开的大写字母和小星号点缀。徽章周围的界面却是「通用的深色后台」：圆角矩形卡片、一像素浅色描边、平涂背景，进度环和按钮都是同一种珊瑚橙，热力图沿用 GitHub 贡献图的方格。两套视觉语言放在一起，徽章像被摆进了管理后台，而不是陈列柜。

具体表现：

- 热力图和进度环是页面上最「数字」的东西，却放在最显眼的位置。365 个高饱和的方块加上斜切双色和小白点，比徽章本身还吵。
- 背景接近纯黑（`#141413`），金属没有可以映照的环境，整页单调。
- 页眉元素小而散，没有形成整体；页面没有页脚，最后一排徽章之后直接结束。

## 方向

以「陈列柜」为主，用「画廊」的克制来把握分寸：

- **陈列柜：** 整页是一个打了灯的勋章陈列柜。界面向徽章学习，直接借用徽章自己的设计语言（外圈的大写字距、金属双圈、小星号、等级金属色），而不是另外发明一套风格。
- **克制：** 材质只出现在三处：背景、进度环、热力图。其余地方靠留白、字体和细线组织版面。原则是「暗示材质，而不是画出材质」，避免拟物过头、显得老气。

## 范围

改：

- 徽章墙主视图：页眉、概览区、热力图、徽章分区标题、筛选控件，新增页脚。
- 弹层（单枚查看、分享海报弹窗、GitHub 主页图弹窗、导出面板）：不改结构，只换成新的颜色、字体和控件变量，保持全页一致。

不改：

- 徽章的 3D 渲染、缩略图、刻字。
- 分享海报和 GitHub 主页图这两张生成的图片（`src/viewer/poster.js`、`src/viewer/shelf.js` 画在画布上的内容）。
- 落地页（`landing.html`、`src/site/`），以后单独做。
- 页面的数据、交互和功能：悬停详情、点击打开徽章、年份切换、工具开关、筛选、语言切换的行为都保持不变。

## 第 1 节：设计基础

全页共用的规则，定义成 `src/styles/tokens.css` 里的变量。后面各节和弹层都只从这里取值。下面给出的色值是起点，第一次截图评审时可以微调；调整只改变量，不改用法。

### 1.1 背景

- 底色从 `#141413` 换成很深的暖炭色，略带棕调，像深色丝绒或胡桃木柜的内衬。起点：`--bg: #15120f`，`--bg-lift: #2a231b`。
- 顶光：页面顶部中央一束柔和的暖光，从上往下渐暗（径向渐变，中心在页面顶部中央偏上，`--bg-lift` 过渡到 `--bg`）。
- 暗角：四周边缘再微微压暗，形成纵深。
- 纹理：叠一层细颗粒纹理，透明度 3%–4%，用内联 SVG 的 `feTurbulence` 生成，不引入图片文件。近看有织物质感，远看仍是干净的深色。
- 背景固定，不随滚动移动（沿用现在的 `background-attachment: fixed`）。

### 1.2 颜色

- **金色是界面唯一的强调色**，取代珊瑚橙 `--accent: #d97757`。用于：进度环、主按钮、胶囊滑块、热力图的解锁标记、装饰线和四角星。
- 金色基于等级金属的金 `#f2c46b`，界面用一个更沉、饱和度更低的版本，避免和金级徽章抢眼。起点：`--gold: #c9a45c`；装饰细线用它的低透明度版本 `--gold-line`（约 0.35）。
- **拉丝金属**：只用在小面积实心元素上（胶囊滑块、主按钮）。用线性渐变表现「亮—中—暗—中」，顶边再加一道一像素的高光，定义为 `--metal-gold`。大面积元素一律不用。
- **等级金属**：银、铜等颜色只在提到徽章等级的地方出现，沿用 `controls.css` 里现有的 `[data-metal]` 变量，不改。
- **品牌色只用于数据**：Claude Code 的橙和 Codex 的蓝（`brand.color`）只出现在热力图的珐琅点、工具图例、热力图悬停详情里，不再用于装饰界面。页眉左侧的标志也不再是橙色。
- 文字色：`--text`、`--muted`、`--faint` 随新底色调整，略偏暖。正文和次要文字对新背景的对比度都要达到 WCAG AA（至少 4.5:1）；`--faint` 只用于不承载信息的装饰。

### 1.3 字体

不引入网络字体，继续用系统字体。

- **衬线体**（现有 `--serif`）：页面标题、分区标题、大数字（解锁数、累计 Token、活跃天数、最长连续、分区计数）。负责仪式感。
- **字距拉开的小字**（新增 `--label` 样式）：所有小标签，例如「最近获得」「即将解锁」「已解锁徽章」、月份、日期。英文用大写，字距约 0.18em；中文同样拉开字距（约 0.12em），字号稍小。这是徽章外圈「CLAUDE CODE」的排法，是界面与徽章最直接的呼应。
- **无衬线体**（现有 `--sans`）：正文、数据说明、按钮文字。
- 数字使用等宽数字（`font-variant-numeric: tabular-nums`），对齐更整齐。

### 1.4 线条与装饰

- **去掉卡片**：概览区的三张圆角卡片和热力图的大卡片都去掉，不再有圆角矩形的底和边框。
- **细双线**取代卡片边框和分隔单线：两条一像素的 `--gold-line` 细线，中间留 2px 空隙，像徽章的金属双圈。
- **四角星**：一个小的四角星图形（内联 SVG），和徽章外圈两侧的星号同形。只用在四处：页眉标志、概览区上方双线的正中、页脚双线的正中，以及空状态的点缀（若有）。不在其他地方使用。

### 1.5 胶囊控件

全页所有「多选一」和「开关」控件统一成一种胶囊，定义在 `controls.css`：

- 外形：细长胶囊，`--gold-line` 细线描边，底色比背景略深，像刻在面板上的一道槽。
- 当前项：下面垫一块拉丝金属滑块（`--metal-gold`），文字为深色；其余项文字为 `--muted`。
- 切换时滑块平滑滑到新位置（约 220ms，缓出曲线）。系统开启「减少动态效果」（`prefers-reduced-motion: reduce`）时直接切换，不播动画。
- 键盘可操作，`focus-visible` 时有清楚的金色焦点环。
- 用于：语言切换、徽章筛选（全部 / 已获得 / 未解锁）、热力图年份切换。热力图的工具开关是「可多选」的，用同一种胶囊外形，但每个工具是独立的开关，打开时垫滑块，关闭时只剩文字。

## 第 2 节：页眉

- **标志**：橙色小菱形换成金色四角星。
- **工具标签**：「Claude Code / Codex」保留衬线体。当前工具更亮，下面一道短金色细线；另一个变暗。
- **副标题**：「成就徽章」改成字距拉开的小字。
- **右侧**：「示例数据」改成同风格的小字标签，只在使用示例数据时出现（行为不变）。
- **语言切换**：换成胶囊，里面并排写「中」和「EN」，当前语言下面垫金属滑块。点击另一侧切换语言，切换方式沿用现在的链接（`[data-lang-switch]` 的跳转逻辑不变，只是变成两个选项）。
- 页眉固定在顶部（行为不变）。滚动后的底部渐隐改用新底色。

## 第 3 节：概览区（铭牌）

整个概览区是一块完整的铭牌，取代三张卡片：

- 上下各一道细双线，上方双线正中放四角星。三栏之间用竖向细线（单线，`--gold-line`）隔开。
- **左栏：铸币刻度环。**
  - 圆环改成一圈细密的径向刻度线，像硬币边缘的齿纹，也像表盘的分钟刻度。刻度固定 120 道，已解锁比例对应的刻度点亮为金色，其余为暗色。
  - 环中间：衬线大字写解锁数，下面小字写「/ 总数」。
  - 旁边三个数字（累计 Token、活跃天数、最长连续）改用衬线大字，标签用字距拉开的小字。
  - 两个按钮改成胶囊形：「生成分享海报」为金属实心胶囊，「GitHub 主页图」为金色细线描边的胶囊。
- **中栏「最近获得」、右栏「即将解锁」：** 结构不变。徽章名称改用衬线体，日期和进度数字用小字。进度条改成一道刻进去的细槽，已完成部分填金色。
- **手机屏幕**：三栏改为上下排列，竖向分隔线换成横向细线；刻度环和数字保持在第一屏可见。
- 保留现有的元素标记（例如 `.profile-count`），供浏览器检查使用。

## 第 4 节：热力图（珐琅刻点）

- 去掉大卡片。标题「年度热力图」用衬线体，下面的统计（总 Token、活跃天数、最长连续）改成小字。
- **格子改成圆点**，像金属板上一排排刻出的凹坑：
  - 没有活动：微微凹下去的暗点（暗色填充，加一道很淡的内阴影或下缘高光，暗示凹陷）。
  - 有活动：点里填珐琅色，用该工具的品牌色，但降低饱和度；用量越大填得越亮（沿用现有的 5 级强度）。
  - 两个工具同一天都用了：左右各半的双色珐琅，取代现在的斜切。
  - 那天解锁了徽章：圆点外加一圈细金边，取代现在的小白点。
  - 未来的日子和年初的占位格：比空点更淡的轮廓点，仍然占位，保证每周一列对齐。
- 月份标签和星期标签改成字距拉开的小字。
- 年份切换改成胶囊；工具开关改成第 1.5 节的多选胶囊；图例「少 … 多」用一排逐级变亮的圆点表示，解锁标记的图例也改成金边圆点。
- 交互不变：悬停显示详情，点击带金边的圆点打开对应徽章。悬停详情浮层换成新的颜色和字体。
- 保留现有的元素标记：`.heat-cell`、`data-date`、`.is-unlock`、`.heat-years`、`.heat-brand`、`data-id`、`aria-pressed`，浏览器检查依赖它们。
- 手机屏幕：热力图仍可横向滚动，看今年时滚到最右（行为不变），页面本身不能出现横向滚动。

## 第 5 节：徽章墙分区

- 「全部徽章」标题用衬线体，筛选改成胶囊（数量仍显示在每个选项里）。
- 每个分类（里程碑、连续与习惯……）下方的单线改成细双线；右侧计数「8 / 8」改用衬线体数字。
- 徽章本身和下面的名称、日期、等级圆点不变。

## 第 6 节：页脚（新增）

- 最后一排徽章之后，留出足够的空白，然后一道细双线，正中四角星。
- 下面一行居中的小字，像藏品图录的版权页：`AGENT BADGES · v<版本号> · GitHub`。
  - 版本号在构建时从 `package.json` 读入（Vite 的 `define`，例如 `__APP_VERSION__`），不硬编码。
  - 「GitHub」链接到项目仓库 `https://github.com/Aryous/agent-badges`，新标签页打开。
- 中英文各一套文案，放进现有的 i18n 字典。
- 不显示「数据更新于」：页面拿不到数据的采集日期，要显示需要改数据格式和采集流程，不在这次范围内。

## 第 7 节：弹层

单枚查看（`inspector.css`）、分享海报弹窗与 GitHub 主页图弹窗（`modal.css`）、导出面板（`export.css`）、通知（`notice.css`）：

- 把写死的颜色换成第 1 节的变量：底色、文字色、细线、强调色。
- 按钮和分段控件换成第 1.5 节的胶囊。
- 标题用衬线体，小标签用字距拉开的小字。
- 不改布局、不改结构、不改交互。

## 实施顺序与评审节点

审美好坏测试判断不了，所以分两段，中间停下来请用户看效果：

1. **第一段**：第 1 节设计基础、第 2 节页眉、第 3 节概览区、第 1.5 节胶囊控件。完成后拍电脑（1440×900）和手机（390×844）的截图给用户看。用户认可方向（或给出调整意见并改完）后才进入第二段。
2. **第二段**：第 4 节热力图、第 5 节分区、第 6 节页脚、第 7 节弹层。完成后再拍一组截图给用户看。

合并到 main 和发布新版本，都等用户看过最终效果后再决定。

## 验收标准

- **徽章渲染零变化**：用 `scripts/visual.mjs` 在改动前后各拍一次（同一天拍），299 张徽章图逐像素一致。这证明只动了界面，没有碰到徽章。
- **功能不坏**：`npm run check:browser` 全部通过，包括手机端陈列墙（含热力图）无横向溢出。必要时只调整检查里依赖旧外观的部分（例如颜色），不得放宽功能判断。
- **单元测试**：`npm test` 全部通过；`npm run check:pack` 通过（新增的页脚版本号注入不能破坏打包）。
- **对比度**：正文和次要文字对新背景达到 WCAG AA（4.5:1）。
- **减少动态效果**：开启 `prefers-reduced-motion` 时，胶囊滑块不播动画。
- **无新依赖**：不新增运行时依赖，不引入网络字体和外部图片。
- **截图**：两个评审节点各提供一组电脑和手机截图，放在 scratchpad，并在汇报里给出完整路径。
