# GitHub 主页徽章陈列图（shelf）— 设计规格

- 日期：2026-10-19
- 状态：已确认设计（形式 B、浏览器渲染、只显示已解锁）
- 相关：`npx agent-badges card`（只有数字和热力图，不含徽章图案）

## 1. 目标

让用户把**已解锁的 3D 徽章**放进 GitHub 个人主页 README，并且 Agent 能用一条命令完成。

## 2. 关键决定

| 决定 | 结论 | 原因 |
|---|---|---|
| 形式 | 单独一张徽章陈列图（不是在 card 里加一排） | 徽章要足够大，金属和等级才看得清 |
| 渲染位置 | 用户的浏览器（WebGL），不在包里预置图片 | 画质最好、包不变大；用户看徽章时浏览器本来就开着 |
| 输出格式 | 透明背景 PNG，2 倍分辨率 | PNG 在 GitHub 一定能显示；透明背景 + 中性灰文字适配深浅两种主题 |
| 显示哪些 | 只显示已解锁；未解锁不显示、不画剪影 | 以后会加新徽章，陈列图不应显得「缺了」 |
| 组标题 | 工具名 + 「已解锁 N 枚」，不写总数 | 总数会随新徽章变化 |
| 文字 | 徽章名 + 等级（分级徽章）；不写日期和用量数字 | 主页公开，只放成就本身 |
| 复用已打开的徽章墙页面 | 不做 | 那个页面属于另一个进程，可能是旧版本；新开标签页落在已打开的浏览器里，体验差别很小 |

## 3. 效果

```
Claude Code                                    已解锁 15 枚
   ◉        ◉        ◉        ◉        ◉        ◉
 首次会话   马拉松   Bash 狂人  夜猫子  1 亿 Token  ...
                                     白金
Codex                                           已解锁 9 枚
   ◉        ◉        ◉ ...
```

- 宽 840（输出 1680 像素），每行 6 枚，徽章约 104 显示像素。
- 工具名用品牌色（Claude Code `#D97757`、Codex `#7A9DFF`），其余文字用 `#8B949E`（GitHub 深浅主题都可读）。
- 徽章按目录顺序排列，布局稳定；已解锁的隐藏徽章显示真名。
- 只包含有本机数据、且至少解锁一枚的工具；`--brand` 可只放一个。
- 在线演示（没有本机数据）里按钮仍可用，画的是示例数据。

## 4. 命令

```
npx agent-badges shelf [--out <文件>] [--brand <claude-code|codex>] [--lang <en|zh>] [--port <端口>] [--no-open]
```

- 默认输出 `agent-badges-shelf.png`，语言默认 `en`（和 card 一致：主页通常是英文）。
- 流程：
  1. 采集本机数据（与其他命令相同）。一枚都没解锁时直接报错，不开浏览器。
  2. 启动本地页面（127.0.0.1，端口规则同徽章墙），打开 `/?task=shelf&nonce=<随机>&shelfLang=<lang>`。
  3. 页面照常显示徽章墙，同时弹出「GitHub 主页图」面板，渲染陈列图，`POST /__agent-badges/shelf?nonce=…` 交回 PNG。
  4. 命令写文件，打印路径和可粘贴进 README 的一行，关闭服务并退出；面板显示「已保存到 …」和预览。
- `--no-open`：只打印网址，等待用户自己打开。
- 超时（120 秒没收到图片）：报错，提示手动打开网址或在有图形界面的电脑上运行。
- 安全：只接受一次、nonce 必须匹配、只接受 `image/png` 且不超过 20MB；文件路径由命令决定，页面无法指定。

## 5. 页面

- 新模块 `src/viewer/shelf.js`：
  - `shelfGroups()`：决定放哪些工具（有本机数据的工具；全无本机数据时用示例数据），每个工具只取已解锁徽章。
  - `renderShelf({ groups, lang })`：用离屏 3D 舞台渲染每枚徽章，再用 2D Canvas 排版成 PNG。
- 徽章墙档案区「生成分享海报」旁加「GitHub 主页图」按钮，打开同一个面板，可下载 PNG。
- 面板复用海报弹窗的样式。

## 6. Agent 技能

`skills/badges/SKILL.md` 增加场景「更新我 GitHub 主页的徽章」：

1. 运行 `npx -y agent-badges@latest shelf --out <主页仓库>/agent-badges-shelf.png`（主页仓库路径问用户，不猜）。
2. 告诉用户 README 里加哪一行。
3. **提交和推送前先问用户**。

## 7. 验证

- 单元测试：参数解析（`shelf`、`--out`）；PNG 接收端（nonce 错误、非 PNG、过大、重复提交都拒绝）；`shelfGroups` 只取已解锁、只取有本机数据的工具。
- 浏览器检查（scripts）：用示例数据渲染陈列图，确认尺寸、组数、无报错，并截图人工看效果。
- 插件测试会自动检查 SKILL.md 里出现的 `--flag` 都被 CLI 支持。
